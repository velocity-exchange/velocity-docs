---
title: "Keeper Bots"
---

Velocity has no central matching engine. The work that a centralized exchange does inside its own process, crossing two orders, noticing that a stop has been hit, closing an account that fell below maintenance margin, is instead done by offchain agents that watch the chain and send the transaction that performs the action. Anyone can run one, and the protocol pays for each action performed.

The four bots below have a tutorial each. All four ship from `apps/keeper-bots-v2` in the `velocity-v1` monorepo, which is not public yet. The wallet, RPC endpoint, config file, and run commands they share are in [Trading Automation](/developers/trading-automation); each tutorial covers only what is specific to its bot.

The first three are keeper duties: the protocol needs them done and pays a fixed reward for doing them. The JIT maker is a trading strategy that happens to ship in the same app. [Keeper incentives](/protocol/how-it-works/keepers/keeper-incentives) covers how the rewards are funded, and [Keepers and the decentralized orderbook](/protocol/how-it-works/orderbook-and-keepers) covers how the DLOB that all of them read is built.
