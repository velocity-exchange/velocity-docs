# Wallet Setup

Velocity supports self-custodial Solana wallets so you can trade, deposit, withdraw, and manage positions. Popular options include [Phantom](https://phantom.com/download), [Backpack](https://backpack.app/download), and [Solflare](https://www.solflare.com/download/). Phantom is the most recommended: it has strong Solana integration, an intuitive interface, broad dApp support, and a smooth connection flow on desktop and mobile.
